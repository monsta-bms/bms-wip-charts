リサイクルセンター

概要＆使い方

リサイクルセンターは、制作途中または完成したBMS差分譜面を共有し、版の分岐と制作進捗を確認できる場所です。 音源は配布せず、差分譜面とその制作情報を扱います。

すぐ使う

新規投稿

  1. 差分ファイルを選ぶ
  2. 曲・差分情報と進捗を確認する
  3. 管理パスワードを設定して投稿する
投稿フォームを開く

追記投稿

  1. 投稿一覧で追記元の版を探す
  2. 「追記投稿」を選ぶ
  3. 新しい差分ファイルと追加進捗を送る
投稿一覧を見る

難易度表を見る

  1. 利用する表を選ぶ
  2. 公開中の完成譜面を確認する
  3. 各譜面の差分ファイルを取得する
RC★ / RC★★

各機能の概要

投稿・追記 進捗マップとミニビュー 難易度表 取り下げ・削除

投稿・追記の使い方

初回投稿では、BMS・BME・BMLまたはZIPを選び、差分名、作者、想定難易度、進捗、管理パスワードを入力します。 ZIPは安全検査を行い、内部に譜面ファイルが1件だけある場合に受け付けます。音声ファイルを含むZIPは投稿できません。

追記は投稿一覧の各版から開始します。追記元の曲・差分情報と進捗レイヤーを引き継ぎ、今回選んだ新しい譜面と追加した範囲を登録します。 公開停止中など、状態によって追記できない版もあります。

新規投稿を始める / 追記元を探す

進捗マップとミニビュー

進捗マップは、譜面全体を標準化したブロックに分け、作成済み範囲と追記者ごとの担当範囲を色で示します。 密度グラフではブロックごとのノーツ量を確認でき、編集レールではクリックやドラッグで進捗を指定できます。

対応する7key SP譜面では、進捗ブロックにポインターを合わせるかフォーカスすると、白鍵・青鍵・スクラッチ・LN・BPM変化をローカルの譜面ミニビューで確認できます。 ミニビュー非対応でも投稿自体は妨げません。

難易度表について

RC★とRC★★は、完成しており、公開中かつダウンロード可能な譜面を配信する読み取り専用の難易度表です。 取り下げ済み、非表示、ファイル削除済みなどの譜面は掲載されません。原曲配布URLが登録されている場合は表にも含まれます。

RC★を開く / RC★★を開く

取り下げ・削除

投稿時の管理パスワードを使い、各版の管理画面から取り下げまたは削除申請を行えます。 取り下げるとダウンロードと追記が停止します。投稿後の経過時間や公開中の子版の有無によって、即時に非表示となる場合と一覧に状態を残す場合があります。

削除申請は管理者の確認対象です。承認後も履歴管理のためデータ行をすぐ物理削除せず、条件を満たした譜面ファイルのみ後日整理します。 管理パスワードは公開されないため、紛失しないよう保管してください。

# UI-LIST-POLISH-01 仕様補足

投稿一覧の分岐ツリー表示と進捗サムネイルは、情報構造を変えずに視認性を上げる。

## ツリー線

- ツリー線は文字記号ではなくCSSの線で表現する。
- ツリー線は版列内だけで完結させ、展開ガター、難易度、作者、進捗、サムネイル、コメント、操作列の開始位置をずらさない。
- 表示中のversion行から接続状態を計算する。
- 中間履歴の折り畳み/展開後も、表示中の行だけを基準に再計算する。
- 次の表示行にも同じ祖先または兄弟分岐が続く場合だけ、該当depthの縦線を継続する。
- 親子関係が切れる位置、または末端ノードでは、不要な縦線を下へ伸ばさない。
- 線色は薄すぎないグレー/青緑グレーを基準にし、版ラベルや難易度を邪魔しない濃さにする。

## 横幅と列

- PC表示ではページ最大幅を1440px程度へ広げる。
- 一覧の列順は `展開 / 版 / 難易度 / 作者 / 進捗 / 進捗サムネイル / コメント / 操作` を維持する。
- 進捗サムネイル列とコメント列に余裕を持たせる。
- DL/追記投稿ボタンは右端の操作列に維持する。
- スマホ幅では従来通り縦積みを許可し、横スクロールを避ける。

## 一覧進捗サムネイル

一覧サムネイルは上段と下段の役割を明確に分ける。

- 上段は高さが変わる密度棒グラフ。
- 上段の棒の高さはノーツ密度を表す。
- 上段の棒の色は、そのblockを最後に塗ったlayer/投稿者を表す。
- 下段は高さ一定の細い進捗レール。
- 下段はblockごとにlayer色で塗り、進捗済み範囲と未着手範囲を示す。
- 下段は棒グラフのように高さを変えない。
- 上段密度バーと下段進捗レールは同じblock indexに対して同じX座標を使う。
- DOM一覧では同じgrid列数、gap、paddingを共有する。
- Canvas PNGでは `plotX`, `plotWidth`, `blockWidth`, `gap`, `xForBlock(index)` を共通計算する。
- 8ブロック区切り線も同じ座標系を使う。

## 未着手・0ノーツ区間

- 未着手blockは背景に溶けない薄緑/ミントで表示する。
- 未着手色は `#CFE3DC`、未着手レールは `#D8E8E2` を基準にする。
- 未着手0ノーツblockでも最低高さ2〜3px程度を表示する。
- 塗り済み0ノーツblockは最低高さ4px程度の色付き表示にする。
- 曲終端まで表示する仕様に合わせ、曲後半の未作成領域が一覧サムネイル上でも分かるようにする。

## PNG生成との整合

- 新規生成される進捗PNGも、一覧サムネイルと同じ上段密度棒グラフ/下段進捗レールの考え方に寄せる。
- 未着手色、最低高さ、上段/下段の位置合わせルールは一覧サムネイルと大きくズレないようにする。
- 既存R2保存済みPNGは自動再生成しない。

## API影響

- Worker API、D1 schema、R2保存処理、progressMap保存仕様は変更しない。
- 本フェーズはGitHub Pages側の表示ロジックとCSS、およびフロントPNG生成見た目の調整のみとする。
